# IRR Web App

แอปดูผลตอบแทน IRR ของแบบประกัน เลือก แบบประกัน → เพศ → อายุ → เบี้ยประกัน → ฐานภาษี แล้วกดคำนวณ
ค่า IRR ทั้งหมดอ่านจาก Google Sheet (แท็บ `irr1`) แอปไม่ได้คำนวณ IRR เอง

```
apps-script/Code.gs   โค้ดที่วางใน Google Sheet (ส่วนขยาย > Apps Script)
web/                  ตัวเว็บแอป อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บโฮสติ้ง
  config.js           ใส่ URL ของ Apps Script ที่นี่
  mock-data.js        ข้อมูลตัวอย่าง ใช้ตอนยังไม่ได้ใส่ URL
scripts/serve.mjs     เปิดทดสอบในเครื่อง: node scripts/serve.mjs → http://localhost:5178
```

## ขั้นที่ 1: Apps Script (ทำครั้งเดียว)

1. เปิด Google Sheet > **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิม วางเนื้อหาไฟล์ `apps-script/Code.gs` ทั้งหมด > บันทึก
3. เลือกฟังก์ชัน `testPayload` > **เรียกใช้** > อนุญาตสิทธิ์ > ดูบันทึกว่าจำนวนแถวถูก และขึ้น "✅ ไม่มีคำเตือน"
4. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้าย `/exec` ไปวางใน `web/config.js` ช่อง `apiUrl`

หมายเหตุ
- แก้ข้อมูลใน Sheet ไม่ต้อง Deploy ใหม่ (แคชจะล้างเองเมื่อแก้ไข และหมดอายุเองใน 10 นาที)
- แก้โค้ด `Code.gs` ต้อง **จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** ทุกครั้ง
- ผู้ที่มีลิงก์ `/exec` ดูข้อมูลในคอลัมน์ที่แอปใช้ได้ (A–J, DX–EA, EC) อย่าใส่ข้อมูลลูกค้าในคอลัมน์เหล่านี้
- ตรวจข้อมูลได้ตลอดด้วยการเปิดลิงก์ `/exec?nocache=1` ในเบราว์เซอร์

## ขั้นที่ 2: เอาเว็บขึ้นออนไลน์

`web/` เป็นเว็บแบบไฟล์ล้วน (HTML/CSS/JS) วางบนโฮสติ้งฟรีใดก็ได้ เช่น
- **Netlify Drop** (ง่ายสุด): เปิด app.netlify.com/drop แล้วลากโฟลเดอร์ `web` ไปวาง
- GitHub Pages หรือ Vercel

## ขั้นที่ 3: ใช้บน iPhone / iPad

เปิดลิงก์ใน Safari > ปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอน "IRR" เปิดเต็มจอเหมือนแอป

## กติกาการแสดงผล

- **IRR หลัก** = คอลัมน์ DX ของแถวที่ตรงกับ แบบประกัน + เพศ + ช่วงอายุ + เบี้ยประกัน
- **ประโยชน์ทางภาษี** (ไม่แสดงเมื่อเลือก 0%): ประหยัดภาษีต่อปี = min(เบี้ย, 100,000) × ฐานภาษี; รวมตลอดสัญญา = ต่อปี × payment (คอลัมน์ J)
- **เงินปันผล** (เมื่อคอลัมน์ F = Yes): 3 บรรทัด จาก G/H/I คู่กับ DY/DZ/EA
- **extra** (คอลัมน์ EC): แสดงท้ายสุดถ้ามีข้อความ (ขึ้นบรรทัดใหม่ในเซลล์ได้)
- ตัวเลือกที่มีค่าเดียว (เช่น ช่วงอายุเดียว) แอปจะเลือกให้อัตโนมัติ
- ค่าเพศ `Male`/`Female` แสดงเป็น ชาย/หญิง ค่าอื่นแสดงตามที่พิมพ์ใน Sheet
